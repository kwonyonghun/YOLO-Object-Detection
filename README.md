# YOLO11 Object Detection and Tracking

## 1. 프로젝트 개요

YOLO11 모델을 활용하여 3개 부류의 객체를 학습하고, 미세조정한 모델을 이용하여 객체 감지 및 추적을 수행하는 프로젝트입니다.

## 2. 학습 데이터

- 데이터셋: 공개 객체 탐지 데이터셋
- 학습 부류: Person(사람), Bicycle(자전거), Cup(컵)
- 모델: YOLO11n
- 학습 횟수: 30 Epochs
- 이미지 크기: 640 × 640
- 학습 환경: Google Colab (NVIDIA Tesla T4)

## 3. 모델 학습 결과

| 평가 항목 | 결과 |
|---|---|
| Precision | 0.772 |
| Recall | 0.242 |
| mAP@50 | 0.243 |
| mAP@50-95 | 0.166 |

### 부류별 mAP@50

| 부류 | mAP@50 |
|---|---|
| Person | 0.537 |
| Bicycle | 0.0227 |
| Cup | 0.171 |

## 4. 객체 감지 및 추적

학습된 `best.pt` 모델을 활용하여 공개 테스트 영상에 객체 감지 및 추적을 적용했습니다.

- 객체 감지: YOLO11
- 객체 추적: ByteTrack
- 결과 영상: 5초
- 결과 파일: `final_result.mp4`

영상 속 객체에 경계 상자와 클래스 이름, 신뢰도 및 추적 ID를 표시했습니다.

## 5. 프로젝트 파일

- `best.pt`: 미세조정한 YOLO11 모델
- `final_result.mp4`: 객체 감지 및 추적 결과 영상

## 6. 결과 분석

사람 부류는 상대적으로 높은 탐지 성능을 보였으나, 자전거와 컵 부류에서는 낮은 성능을 기록했습니다.

특히 자전거의 탐지 성능이 낮아, 향후 학습 데이터의 다양성과 수량을 늘리는 방법으로 성능 개선을 시도할 수 있습니다.
